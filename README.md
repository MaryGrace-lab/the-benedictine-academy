# THE BENEDICTINE ACADEMY

Benedictine Academy Website
This repository contains the source code for the official Benedictine Academy website. The primary goal of this site is to provide information for prospective students and their families, with a focus on admissions.

## Features
Online Application Page: A form for new student applications.

Fees and Funding Section: A clear breakdown of tuition and payment details.

Admissions Requirements: A list of all necessary documents and criteria for admission.

Responsive Design: The site is designed to look great on both desktop and mobile devices.

## How to Use
To view and test this website on your own computer, simply open the index.html file in your preferred web browser.

## Technologies Used
Technologies Used
HTML: For the website structure.

CSS: For all styling and layout, including responsive design.
